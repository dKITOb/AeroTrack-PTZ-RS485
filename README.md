# 🚀 AeroTrack PTZ Controller v1.0 - RS485 Edition

Профессиональная система управления наземной антенной (PTZ - Pan-Tilt-Zoom) с модульной архитектурой, RS485 TTL подключением и поддержкой расширения.

## 📋 Возможности

✅ **Модульная архитектура** - легко добавлять новые функции  
✅ **RS485 TTL связь** - надёжная и помехоустойчивая  
✅ **4 режима управления** - TILT+PAN / TILT / PAN / CHANNELS  
✅ **Компас HMC5883L** - определение направления с калибровкой  
✅ **Управление модулями** - включение/отключение функций через меню  
✅ **TFT экран 1.8"** - интерактивный интерфейс  
✅ **EEPROM сохранение** - сохранение параметров  
✅ **Диагностика** - проверка состояния всех компонентов  

## 🔧 Требуемые компоненты

### Блок 1 (Контроллер)
- ESP32-S3-N16R8
- 2x Сервомотор (Pan/Tilt)
- HMC5883L Компас
- RS485 TTL модуль (MAX485 или аналог)
- Витая пара LAN кабель (2-4 жилы для A, B, GND)

### Блок 2 (Пульт)
- ESP32-S3-N16R8
- TFT ST7735 1.8" экран
- Джойстик (аналоговый)
- Кнопка (1x)
- RS485 TTL модуль (MAX485 или аналог)

## 🔌 RS485 подключение

```
ЭСП32 GPIO 17/18 ──→ RS485 модуль RX/TX
ES32 GND ──→ RS485 GND

RS485 A ──→ витая пара A (контроллер и пульт)
RS485 B ──→ витая пара B (контроллер и пульт)
```

## 🎮 Управление

### Пульт
- **Короткое нажатие кнопки** - переключение режима
- **Долгое нажатие (1 сек)** - открыть главное меню
- **Джойстик** - управление в зависимости от режима
- **Кнопка MENU на экране** - быстрый доступ к менеджеру модулей

## 📊 Модули

- ✅ **Servo Control** - управление сервомоторами
- ✅ **Compass** - компас с калибровкой
- ✅ **Frequency** - переключение каналов
- ✅ **Telemetry** - телеметрия (опционально)

## 🚀 Быстрый старт

1. Подключите компоненты согласно `WIRING.md`
2. Загрузите `Block1_Controller.ino` на первый ESP32
3. Загрузите `Block2_Remote.ino` на второй ESP32
4. Откройте Serial Monitor (115200 baud)
5. Используйте пульт для управления
